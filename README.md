# MacrosFirst Growth Audit

**Live → https://eddieatadapty.github.io/macrosfirst-flow-rebuild/**

Five ideas to turn more MacrosFirst users into subscribers, each built into a clickable version of MacrosFirst's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Carry the plan they built all the way to the price | +10–20% CR to purchase |
| 02 | Let them log one meal before the price | +5–15% CR to purchase |
| 03 | Put the 50% on the first paywall, not behind “View all plans” | +5–15% ARPU |
| 04 | Ask for the account after the free week starts | +5–10% CR to purchase |
| 05 | Offer monthly to people who close the paywall | +5–10% CR from paywall closers |

Every price, rating and feature comes from MacrosFirst's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for MacrosFirst. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
